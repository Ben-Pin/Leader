# Changelog

Public release baseline: 1.0.0. Corrections made during initial release preparation remain in this baseline; development after publication continues on branch 1.1. Functional additions/changes advance MINOR; fixes/docs advance PATCH; breaking compatibility advances MAJOR. This is a local browser application, not a packaged installer or cloud deployment.

## 1.0.0 - 2026-10-05

- About, README and the English manual emphasize local database storage, no application uploads and the deliberate single-user product principle; optional MCP host access has its own clearly described boundary.

- Both list and full company exports have the requested local ddmmhh-hhmm timestamp, with Documents suggested by compatible browser save dialogs.
- Fresh installations connect only the fictional woodland Demo; existing customer databases remain intact.
- About uses the same Leader wordmark, font and dot as the sidebar header.

- Expanded the English user manual with a photographed, numbered guide to all ten blue-toolbar buttons.
- Documented Auto-tag scope, quarter calculation, automatic future-year groups, missing-date handling and repeat-run counts.
- Added screenshots and step-by-step instructions for active flag comments and dated enabled/disabled History events, including resolution text entered before disabling a flag.
- Added the application software stack and regenerated the bundled local PDF.
- The About manual link uses the release-specific PDF filename to avoid cached older editions and allow an older file to remain open in an external reader.


- Six permanent account lists in spectrum order; Agents replaces Distributors. List visibility settings and dated saved move history.
- Independent Contact, Evaluation, Ramp Up, Production and Legacy stages; Priority filters/sorting and compact list markers.
- User settings for profile/motto, Wisdom, list visibility and a square custom background map at 70% opacity.
- Sixty finished collectible PNG game pieces; Mascot opens first, including Lucky cat and Einstein. Fully decoded image batches and in-place held enlargement.
- Documentation refresh: English Markdown and bundled PDF user manual accessible locally from About, current product/architecture/API/MCP descriptions, documentation index and setup/recovery guidance.
- Woodland Demo with twelve fictional animal-run companies, multiple contacts and discussion history. Illustrated instructions and sixty game-piece personality stories.
- About shows a large random finished piece on each opening, product credit and the manual link. The supplied transparent white chip logo appears in a slightly larger, centered rail button and throughout the application.

### Included from pre-release work

- Multiple isolated company databases, portable company JSON, disconnect/reconnect and automatic local JSON snapshots.
- Autosave with unsaved-draft Undo, contact statuses and participant-linked discussion history.
- Five attention flags with comments, dated on/off events and UI contact-date updates.
- List JSON import/export, category-routing choices, Imported markers and export privacy switches.
- Paginated search, filtered globe/country directory, country point distribution, tags/categories and future contact-quarter synchronization.

- The motto remains visible when browser zoom triggers compact-height layout; the settings label is Leader's motto. Compact add/import/export controls share the flag-filter row.
- Corrected the data audit to recognize all six permanent lists, including Agents.

## Current limits

Single-user loopback operation; Windows verified. No cloud sync, built-in PST/mail/TickTick importer, reminders, attachments or outgoing email. Wisdom awaits a content source; pointer-directed figure lighting is research. Linux/ARM64, macOS and actual MCP-host installation are not verified by the local Windows test suite.
